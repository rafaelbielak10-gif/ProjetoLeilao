Sobre o projeto

O projeto consiste em um sistema informatizado para auxiliar uma casa de leilões no controle e gerenciamento de produtos cadastrados para venda.

O sistema permite o cadastro e a consulta de produtos, além do controle do valor e do status dos itens, identificando produtos que estão à venda e produtos que já foram vendidos.

O objetivo é facilitar a organização das informações e substituir controles manuais por um sistema informatizado.
